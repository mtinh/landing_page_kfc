# KFC Landing Page Demo

Mở thư mục trong VS Code, nhấp chuột phải `index.html` → **Open with Live Server**. Hoặc chạy `python -m http.server 8000` và truy cập http://localhost:8000.

Dữ liệu menu nằm trong `kfc-menu.csv` (UTF-8). Sửa CSV để cập nhật giá/tên/mô tả, dùng `TRUE` cho Best Seller. Nút Xem chi tiết mở `product.html?id=...`. Ảnh SVG là minh họa và có thể thay bằng ảnh riêng, chỉ cần cập nhật cột `hinh_anh`.

Giỏ hàng demo chỉ lưu trong localStorage, chưa có checkout/backend. Không phải trang KFC chính thức.
